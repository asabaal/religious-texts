🚀 Complete Setup & Usage Guide

Everything you need to start generating AI-powered biblical content

🔧 Prerequisites & Setup

1. Install Ollama & Llama 3.1 8B

$ # Install Ollama (if not already installed)
$ curl -fsSL https://ollama.ai/install.sh | sh
$ # Pull the Llama 3.1 8B model
$ ollama pull llama3.1:8b
$ # Start Ollama service
$ ollama serve

2. Install Python Dependencies

$ # Install required packages
$ pip install requests nltk scikit-learn
$ # Download NLTK data (first time only)
$ python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords')"

🛠️ Troubleshooting

Common Issues & Solutions

❌ "Ollama connection failed"
Solution: Make sure Ollama is running with ollama serve and the model is installed with ollama pull llama3.1:8b
❌ "No passages found for concept"
Solution: The concept might be too specific. Try broader terms or add more biblical passages to rag.py
❌ "JSON parsing error"
Solution: The AI response might be malformed. The system includes fallbacks, but you can try regenerating or adjusting the temperature parameter.
❌ "NLTK data not found"
Solution: Run python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords')" to download required data.
